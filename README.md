# Java-practice-code

My daily Java programming practice codes, from basics to advanced.

## 🗂️ Topics Covered (Learning Path)

Here is the structure of the practice codes I will be uploading:

### 1. Basics
* Hello World
* Data Types & Variables
* Conditional Statements (If-Else, Switch)
* Loops (For, While, Do-While)
* Pattern Printing

### 2. Arrays & Strings
* 1D and 2D Arrays
* String Manipulation
* StringBuilder & StringBuffer

### 3. Object-Oriented Programming (OOPs)
* Classes & Objects
* Methods & Constructors
* Inheritance, Polymorphism, Encapsulation, Abstraction

### 4. Advanced Topics (Upcoming)
* Exception Handling
* Collections Framework (List, Set, Map)
* Multithreading

## 🚀 How to Run

To run these Java programs on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vishvender-singh/Java-practice-code.git
   ```
2. **Navigate to the folder:**
   ```bash
   cd Java-practice-code/01-Basics
   javac First.java
   java First
   ```
(Note: Make sure you have the Java Development Kit (JDK) installed on your system and environment variables set.)
