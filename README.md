## 🚀 How to Run

To run these Java programs on your local machine:

1. **Clone the repository:**

    git clone https://github.com/vishvender-singh/Java-practice-code.git

2. **Navigate to any topic folder and run a program:**

    cd Java-practice-code/01-basics
    javac First.java
    java First

*(Note: Make sure you have the Java Development Kit (JDK) installed on your system and environment variables set.)*
